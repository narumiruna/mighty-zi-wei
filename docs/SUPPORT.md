# 支援

如需回報排盤差異、操作問題或無障礙問題，請至 GitHub repository 建立 issue。

回報排盤差異時，請附上公曆出生日期、當地時間、IANA 時區，以及用來核對的流派與來源。

請勿在公開 issue 提供真實姓名或其他不必要的個人資料。

## 語音輸入

若麥克風或語音辨識權限曾被拒絕，請到 iPhone「設定」找到「很牛的紫微斗數」，再允許麥克風與語音辨識存取。

若畫面持續顯示正在準備正體中文語音辨識，請確認網路可用且裝置有足夠儲存空間，然後停止並重新嘗試。

若這台 iPhone 不支援所需的正體中文語音資產，仍可直接使用鍵盤輸入問題。

辨識結果只會填入問題草稿，請先檢查文字，再自行按下送出。

## 加密備份與還原

建立備份後，請先完成檔案儲存，再將畫面顯示的復原金鑰保存於不同位置。

App 不會保存復原金鑰，也無法協助找回遺失的金鑰。

還原失敗時，請確認選擇的是 App 建立的備份檔，且貼上的復原金鑰沒有多餘空白或缺字。

若備份檔遭修改、損毀或超過 10 MiB，App 會拒絕還原。

還原相同識別碼的命盤時，備份內容會取代該命盤與整本筆記、收藏。

本機較新的筆記或收藏若不在備份中，也會在確認後永久刪除；其他本機命盤與其內容會保留。

## App 鎖

App 鎖使用系統 Face ID、Touch ID 或裝置密碼。

若無法啟用，請先在 iPhone「設定」中完成 Face ID、Touch ID 或裝置密碼設定。

切到背景後 App 會立即鎖定；回到前景時可以再次點選解鎖按鈕。

## iCloud 同步

同步預設關閉，首次開啟時會先顯示會同步與不會同步的資料。

只有點選「啟用並同步」後，App 才會先顯示已啟用並開始同步；取消揭露不會啟用同步。

若同步因 iCloud 帳號狀態而未完成，請確認 iPhone 已登入 iCloud、iCloud Drive 可用，而且允許 App 使用 iCloud。

若顯示「同步未完成」，App 仍會保持同步啟用，而且 iCloud 可能已收到部分資料。

請保留網路連線並點選「重試同步」；重試會沿用相同資料識別碼，不需要先關閉同步。

本機資料會在同步失敗後保留。

版本衝突會保留修改時間較新的內容，刪除則透過 tombstone 傳到其他裝置。

關閉同步只會停止後續同步，不會自動刪除 iCloud 已有資料。

AI 對話、API 設定、API key 與裝置通知識別碼不會同步。

## 回顧提醒

首次設定回顧日期時，請允許通知權限。

若曾拒絕通知，請到 iPhone「設定」找到「很牛的紫微斗數」並開啟通知。

回顧日期完全由使用者指定，不是流年、吉凶或事件預測。

## 已儲存命盤與收藏

若「已儲存」分頁沒有命盤，請點選「排一張命盤」開始建立命盤。

若搜尋沒有結果，請點選「清除搜尋」。

若篩選沒有結果，請點選「清除篩選」。

若搜尋與篩選同時生效，請點選「清除全部條件」，或從篩選選單逐項調整。

未儲存命盤的收藏按鈕會停用，旁邊會顯示「先儲存命盤才能收藏」。

請先在命盤頁儲存命盤，再收藏解讀段落或命盤助理回答。

## 命盤解讀版本

進入命盤解讀後，畫面第一個區塊會顯示目前是「基本解讀・本機」或「AI 整理・第三方」。

取得通過驗證的 AI 整理後，可以用「基本解讀」與「AI 整理」按鈕切換版本。

基本解讀會一直保留，重新整理失敗、驗證失敗或取消不會刪除基本解讀或上一份有效 AI 版本。

若 AI 整理失敗，請繼續閱讀目前版本，或檢查 API 設定後重新嘗試。

## API 設定與安全復原

API 設定頁的 endpoint、model、API key、回答長度與每月上限都是尚未儲存的畫面草稿。

「測試目前欄位」會測試草稿、記錄一次本機請求並可能產生第三方費用，但不會儲存草稿，也不會傳送命盤資料。

確認欄位後請點選「儲存 API 設定」；直接返回或取消會捨棄未儲存變更。

若儲存或清除失敗且畫面表示先前設定未變更，請稍後重新操作。

若畫面顯示「需要重新設定」，代表 App 無法完整復原先前設定，而且 AI 已安全停用。

請先點選「重新載入並檢查欄位」，重新確認 endpoint、model 與 API key，再點選「儲存 API 設定」。

若畫面顯示「API key 暫時無法使用」，請先解鎖裝置；App 會保留設定，並在回到前景後自動重試。

若 Keychain 內容持續無法讀取，請選擇「移除無法讀取的設定」，確認移除後再重新輸入並儲存。

在成功儲存前，本機排盤、命盤閱讀與基本解讀仍可使用。

## 命盤助理問答

若回答逾時、連線失敗或服務商暫時限制請求，問題會保留在輸入框，請稍後點選「重新送出」。

若畫面提示授權或設定問題，請使用「檢查 API 設定」確認目前設定與連線測試。

若回應格式不相容、命盤依據不完整或內容未通過安全驗證，App 不會顯示未驗證回答，既有成功回答仍會保留。

你主動停止等待後仍可修改或重新送出問題，但第三方服務可能已開始處理並產生費用。

切換 App 內底部分頁不會停止已送出的問答。

若要永久保留目前內容，請先儲存目前命盤，再查看對話中的保存狀態並點選「保存對話」或「更新已保存對話」。

命盤尚未儲存時，「保存對話」會停用並顯示原因；目前草稿與回答不會因此被清除。

保存失敗時目前對話仍會留在畫面，請確認裝置有足夠空間後重新保存。

已保存副本可從命盤助理右上角的「已保存對話」查看、搜尋、重新命名或匯出。

## AI 用量與診斷

每月請求上限是 App 在本機記錄的保護值，不是第三方帳單或精確 token 數。

若 API 操作失敗，可在 API 設定頁一鍵複製安全診斷。

安全診斷不含 API key、endpoint、prompt、命盤或服務回應內容。

## 語音朗讀

若沒有聲音，請先確認媒體音量、目前連接的耳機或藍牙裝置，以及控制中心顯示的音訊輸出路徑。

若朗讀因來電、其他 App 播放音訊或切換輸出裝置而停止，請回到原段落重新點擊「朗讀」。

語音功能失敗不會影響文字閱讀、排盤、基本解讀或鍵盤提問。
