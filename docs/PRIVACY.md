# 隱私權說明

很牛的紫微斗數不需要建立 App 帳號，也不建立開發者控制的後端服務。

App 不會將你的出生資料、命盤、prompt 或解讀內容傳送到我們的伺服器。

出生資料、已儲存命盤、標籤、釘選狀態、私人筆記、自我觀察標記、回顧日期、收藏與使用者主動保存的 AI 對話使用 SwiftData 保存在本機。

解讀收藏與觀察筆記可以保存顯示文字、內容位置與對應的 `evidenceFactIDs`。

AI 回答只有在你主動收藏單則回答，或主動選擇「保存本次對話」後才會永久保存在本機。

保存的完整對話會保留當時的命盤名稱、命盤時間、模型名稱與問答內容，但不會納入加密備份或 iCloud 同步。

iOS 仍可能依使用者的系統設定，將 App 資料納入裝置備份或裝置移轉。

App 鎖是選用功能。

開啟後，App 使用 Apple `LocalAuthentication` 驗證 Face ID、Touch ID 或裝置密碼，不會取得或保存生物特徵資料與裝置密碼。

App 切到非使用中或背景狀態時會立即遮住內容並重新鎖定。

觀察回顧提醒也是選用功能。

只有你主動指定回顧日期時，App 才會要求通知權限並建立本機通知。

提醒日期不由命盤推算，也不代表事件、吉日或凶日。

AI 解讀是選用功能。

語音輸入也是選用功能，而且只用於建立「命盤助理」的可編輯問題草稿。

首次使用語音輸入時，iOS 會要求語音辨識與麥克風權限。

正體中文語音資產可能需要由 Apple 下載到裝置，下載行為與資產由 iOS 管理。

App 不會錄製成音訊檔案，也不會保存、匯出或分享麥克風音訊。

辨識結果只會先更新裝置上的問題草稿，不會自動送出或產生第三方 API 費用。

朗讀命盤解讀或回答時，App 使用 Apple 提供的裝置語音，而且只有你主動點擊朗讀後才會播放。

使用 AI 解讀前，你必須自行設定 HTTPS OpenAI 相容 API base URL 或完整 Responses API endpoint 與模型名稱；未以 `/responses` 結尾時 App 會自動補齊路徑，不要求 Bearer token 的相容服務可將 API key 留空。

Endpoint、model、API key、回答長度與每月請求上限會先保留為設定畫面中的本機草稿。

「測試目前欄位」只使用這份草稿進行連線測試，不會把草稿儲存成 API 設定。

取消或返回會捨棄未儲存草稿，只有你明確點選「儲存 API 設定」後才會套用全部欄位。

API key 儲存在不可同步、僅限本裝置且解鎖時可讀的 iOS Keychain item，不會寫入 SwiftData、診斷記錄或 repository。

非空的 API key 只會作為 `Authorization` header 傳送到你設定的 endpoint。

你主動使用「測試目前欄位」時，App 會將草稿中的 endpoint、model 與非空 API key 用於不含命盤資料的小型 structured output request，且第三方服務商仍可能計費。

有效的測試請求送出前會記錄一次本機請求，並更新畫面上的測試狀態，但不代表草稿已儲存。

每次使用 AI 整理文字前，App 都會先顯示傳送預覽。

AI 整理預覽第一層會說明只整理既有文字，並顯示必要命盤依據與一次本機請求影響。

命盤 facts、interpretation seeds、模型、數量與不會傳送的欄位放在你可以主動展開的詳細資料。

返回閱讀、取消或關閉 AI 整理預覽不會增加本機用量、呼叫 API 或改變目前內容。

命盤助理會在你點選送出問題後，以非串流 HTTPS 請求將回答所需的命盤 facts、interpretation seeds、文字問題、本次對話、prompt 與技術性請求資料直接傳送至你指定的第三方服務商。

AI 整理會在你最後主動確認後，以相同方式傳送整理所需的命盤 facts、interpretation seeds、prompt 與技術性請求資料。

這些資料離開裝置後，會依該服務商的服務條款、隱私政策、資料保留設定與所在地法規處理。

App 不會主動把命盤名稱、原始出生日期、出生時間或 `BirthProfile` 加入 AI 請求，但你自行輸入在問題中的內容仍會傳送給第三方服務商。

切換 App 內底部分頁不會停止已送出的命盤助理請求。

只有你明確停止、確認清除、確認切換命盤或 App process 終止時，App 才會取消本機等待工作。

停止等待無法保證第三方服務停止處理，服務商仍可能已經產生 token 費用。

停止、逾時或失敗會保留問題草稿與既有成功回答。

本次對話會持續顯示尚未保存、已保存到第幾輪，以及後續尚未保存的輪數。

第一次主動保存會建立本機副本，同一個 App session 再次保存會更新同一筆副本。

尚未主動保存的命盤助理對話在 App process 終止或確認清除對話後無法復原。

使用者可以設定每次回答字數與每月本機請求次數上限。

本機請求計數不是第三方帳單，不包含精確 token 或實際費用。

失敗時產生的安全診斷只包含時間、操作類型、去識別化錯誤代碼、請求計數與 iOS 版本。

安全診斷不包含 API key、endpoint、prompt、命盤或服務回應內容。

後續追問會重新傳送本次對話中先前已驗證的問題與回答，以便模型理解脈絡。

請勿設定你不信任的 endpoint，並在啟用前查閱服務商的隱私與安全說明。

第三方服務商可能依請求量、token 用量或其方案另外收費。

這些費用不包含在 App 買斷價格內，也不由 App 開發者代收或控制。

若 API 未設定、無法連線、回應無效或內容驗證失敗，App 的本機 deterministic 基本解讀仍可正常使用，既有成功對話也不會被失敗請求覆蓋。

儲存或清除 API 設定失敗時，App 會在目前執行程序內嘗試復原先前的 endpoint、model、API key、回答長度與每月上限。

若連復原也無法完整完成，App 會清除可啟用請求的 endpoint 與 model 狀態、重新載入實際可讀的持久化值並停用 AI，直到你重新檢查所有欄位並成功儲存。

裝置鎖定造成 Keychain 暫時不可讀時，App 會保留既有設定，並在受保護資料可用或回到前景後自動重試。

若 Keychain 項目本身無法讀取，你可以明確確認移除該憑證與非秘密 API 設定，再重新設定；App 不會在未確認時自行忽略損毀憑證並傳送請求。

UserDefaults 與 Keychain 不具共同 transaction，因此 App 無法保證系統在兩個儲存操作之間終止程序時仍可完成同一套程序內復原。

停用 AI 解讀不影響排盤、命盤閱讀、基本解讀或本機儲存。

命盤文字分享預設不包含名稱、出生日期、出生時間或時區。

只有你主動開啟個資選項、再次確認將包含的欄位，並使用 iOS 分享面板時，這些資料才會交給你選擇的分享對象或 App。

iCloud 同步預設關閉。

首次開啟時，App 會先揭露會同步的命盤、標籤、釘選狀態、筆記、回顧日期、收藏與刪除紀錄，以及不會同步的資料。

取消揭露不會啟用同步或傳送資料。

你確認「啟用並同步」後，App 會先保存已啟用狀態並顯示等待同步，再把資料同步到你 Apple ID 的私人 CloudKit 資料庫。

同一筆內容發生衝突時，App 會保留 `updatedAt` 較新的版本，並以 tombstone 同步刪除。

同步會逐筆處理資料，因此失敗時 iCloud 可能已收到部分變更。

同步未完成時，App 會保持啟用、保留本機有效資料並提供重試，不會假設或宣稱遠端完全沒有變更。

關閉同步只停止後續同步，不會自動刪除私人 CloudKit 資料庫中的既有資料。

API key、endpoint、模型設定、AI 對話與裝置通知識別碼不會進入 CloudKit。

CloudKit 由 Apple 提供，資料依 Apple 的 iCloud 條款與隱私政策處理。

隱私模式 Widget 只讀取 App Group 中的下一個自訂回顧時間，不顯示姓名、出生資料或命盤內容。

App Intents 可以開啟釘選命盤、新增觀察筆記或建立可編輯的 AI 問題草稿。

AI 問題捷徑不會自動送出或產生第三方 API 費用。

你可以主動建立 AES-GCM 加密備份。

備份只包含命盤 source-of-truth、私人筆記、自我觀察標記與收藏，不包含 API key、endpoint、模型名稱、AI 對話或衍生命盤快取。

每份備份使用新的隨機 256-bit 復原金鑰，而且 App 不會保存金鑰。

你必須將備份檔與復原金鑰分開保管；遺失金鑰後，App 與開發者都無法解密備份。

你選擇的檔案儲存位置、分享服務或雲端硬碟會依其自身隱私政策處理備份檔。

App 不包含第三方分析、廣告或當機回報 SDK。

你可以刪除單張命盤或所有已儲存命盤；刪除命盤時會一併刪除其本機筆記與收藏。

你也可以在「設定」中另外清除 endpoint、model、回答長度與 Keychain 中的 API key；每月上限與既有用量紀錄會保留。
